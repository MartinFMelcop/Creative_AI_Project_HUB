# Visual Identity & Animation Laboratory

## Question and source boundary

Can source-derived atlas regions and alpha-foot registration retain correct cropping,
scale and mirrored anchoring where fixed-cell and fixed-pivot policies disagree?
Can the same principle of presentation following owned gameplay state feed an actual
North Star visual consumer without importing historical fiction?

P07 owns this destination. The assay consumes the exact two accepted P06 PNGs,
`motion-catalog.json`, `tools/build_motion_catalog.gd`, `motion.gd` and provenance.
The PNGs and original project are never rewritten. Their generated-image provenance,
rejected generations, limited four-pose clips, mirroring and rights limits remain.
Source bodies/attacks are not approved North Star characters or canon.

## Executable source method

```bash
python3 labs/visual-animation/test_instrument.py
python3 labs/visual-animation/run.py --output /tmp/visual-source.json
python3 labs/visual-animation/run.py --output /tmp/visual-repeat.json --compare /tmp/visual-source.json
```

Requires Python standard library and Godot available as `godot` (or `--godot`).
Output must be outside maintained sources. Exact comparison includes source hashes,
Godot version and all observations; it ignores no changed results or fingerprints.
Missing tools, import failures and native crashes fail execution rather than counting
as detected mutants. Subprocesses have a 120-second timeout.

The independent PNG reader verifies CRCs, decompresses actual RGBA8 scanlines and
reconstructs all five PNG filter modes. It derives 32 occupied cells, gutters,
opaque bounds, alpha-foot pivots and maximum-height scale. Non-divisible 1254-pixel
sheets require alternating 313/314-pixel regions. Comparison uses exact catalog
values, not enlarged tolerances. The native channel is float32: alpha byte 32 becomes
slightly greater than the producer's double `32.0/255.0` threshold. A simpler integer
`alpha > 32` changes 14 pivots; that semantic difference is retained explicitly.

The actual preserved Godot catalog producer runs in a temporary minimal project.
Its decoded output must equal the preserved catalog. A staged copy of `motion.gd`
executes 20 actual runner/warden selector controls and 64 mirrored draw-call controls.
Only its `canvas: Node2D` parameter annotation is removed so a recorder can receive
native draw arguments. Selector and crop/transform arithmetic are otherwise unchanged.
This is native source execution with renderer I/O recorded, **not actual Godot pixel
rendering**. The isolated wrong-anchor mutant changes vertical offset 22 to 23 and
must fail the registration assertion with a specific marker and exit status.

## Controls and decision

Independent registration checks cover every frame at the source scale and absolute scales 0.5, 1,
2, each mirrored and unmirrored: 256 checks. Fixed 313-pixel cells and
constant first-frame pivots are retained rejected policies with affected frame IDs.
The source-derived method is technically usable; fixed policies are rejected for
this input, rather than declared universally invalid. Alpha-foot placement is a
registration convention, not an anatomical truth or evidence of plausible movement.

Eight instrument regressions cover all PNG filters, corruption, trailing bytes,
invalid filter, empty cells, mirror arithmetic, source-output exclusion and the
float32 threshold boundary. They are not independent users or additional animations.

The browser destination instrument is coordinated separately in `browser.mjs`.
It must execute actual C# snapshots and inspect actual destination rendering and
pause/state behavior. Source-registration results alone do not demonstrate that
consumer or justify a browser-rendering claim. No physical asset needs to be copied
into the destination to transfer the inspected registration/state-selection method.

## Actual destination and selection

Independent Engineering, Scientific and Creative analyses compared incomplete Visual,
Audio, AI Evaluation and Windows delivery. Engineering preferred low-coupling relay
presentation; Creation preferred visible independent Crossing identity and consequence.
The selected [Crossing presentation](../../north-star/csharp/Presentation/README.md)
executes unchanged owner source and adds original registered bodies and static accepted
beat/event poses, rather than another preparation subsystem. Science kept geometry and
state correspondence separate from human recognition. Audio remains a strong rival;
the public AI practice task is not independent unseen evaluation; current bounded tool
probes did not find a licensed Unity Editor/Windows module.

The browser instrument reuses the existing locked playwright-core1.64.0 in
`projects/realtime-integration-lab`; install with that project's lockfile and set

and closes its own bounded actual C# host/browser, records actual owner observations,
asserts actual SVG shape/pose/contact/foot-root state and captures rendered images.
Images are inspected separately; DOM assertions alone are not raster/readability proof.
An isolated actual renderer mutation inventing protection on a damaging walk must fail
the specific state/render oracle. Network/blur interventions are synthetic controls.
