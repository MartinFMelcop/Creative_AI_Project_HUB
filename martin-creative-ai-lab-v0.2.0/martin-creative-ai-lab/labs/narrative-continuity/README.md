# Narrative & Continuity Laboratory

## Beneficiary and consequential question

North Star needs authored NPC requests whose consequences survive a conversation:
what was refused, what changed, who volunteered, what was actually delivered, and
what remains merely promised. Existing combat/preparation and local recovery do not
supply these semantics. This bounded method asks whether an original request and
actual encounter can distinguish tentative proposal, contextual consent, commitment
and observed completion without rewriting prior facts or treating a person as cargo.

Independent Engineering, Scientific and Creative analyses selected this frontier
against additional local recovery, AI task evaluation, input timing and actual Unity
production delivery. Recovery already has bounded process/file evidence; repeating
it would add less experiential breadth. The existing public AI practice task needs
explicit independent-candidate/context controls before model-performance claims.
Input timing has a strong executable origin but no current request/quest semantics.
Unity delivery depends on an actually available supported Editor/license/modules.
Creation's previously deferred narrative concern now changes the implemented consumer.
This is a bounded authored experiment, not final class/world canon or proven enjoyment.

## Boundary and next objective

This local Linux/.NET experiment provides consequential authored request/quest
continuity with actual combat consumers. It does not supply Unity Editor integration,
Windows/Steam delivery, durable account ownership, production NPC AI, unconstrained
natural-language dialogue, final reputation/class canon or independent human review.
Next investigate authored comprehension and agency with appropriate human evaluation,
additional NPC/quest content and migration/recovery contracts before combining save
formats or claiming a persistent world. Preserve actual historical consumers until
behavior, save compatibility, source/rights and recovery duties are resolved.
