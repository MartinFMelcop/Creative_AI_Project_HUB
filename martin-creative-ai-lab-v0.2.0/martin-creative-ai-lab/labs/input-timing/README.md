## Reproduce from the maintained workspace

Use SDK10.0.401 and Node24.19.0:

```bash
python3 -m unittest discover -s labs/input-timing -p 'test_*.py'
python3 labs/input-timing/run.py --dotnet dotnet --output /tmp/input-timing.json --compare evidence/input-timing/results.json
node labs/input-timing/browser.mjs dotnet /tmp/input-browser
```

The browser instrument reuses the existing locked playwright-core1.64.0 in
`projects/realtime-integration-lab`; install with that project's lockfile. Set
CHROMIUM_PATH to its matching installed executable (local default/usr/bin/chromium).
CI installs that existing pinned package/browser, not a new dependency stack.
It starts a bounded actual C# host, uses real browser input, inspects returned states,
records actual images and closes its own browser/server. Synthetic blur and dropped
requests are explicit interventions, not observed hardware faults.

The deterministic runner fingerprints its exact sources/new C# projects/web files
before/after, refuses maintained-tree outputs, validates complete consequences and
supports exact result comparison. The [execution record](../../evidence/input-timing/RUN.json)
separates deterministic/native/origin proof from browser wall time/rendering.
Do not compare raw browser timestamps or PNG bytes across hosts as gameplay equality.

## Consumer decision and retained boundaries

work, discards partial progress after interruption, pays grounding once and requires
both catches plus actual living exit. Rhythm regrab/tail forgiveness is retained in
its origin and rejected as a blind adapter for this different interaction. A600ms
missing-input lease is bounded uncertainty; it cannot promise immediate detection of
a physical release or guarantee network exactly-once input.

parity, rhythm audio playback, a new production engine, Unity/Windows/Steam, persistent
world ownership, human readability, accessibility, preference or scientific latency
validation. Four destinations remain incomplete after this bounded method operates.
