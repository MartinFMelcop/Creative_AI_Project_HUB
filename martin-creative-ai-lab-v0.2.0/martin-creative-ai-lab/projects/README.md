# Working projects

[P11 — Live exchange](realtime-integration-lab/README.md) is the first executable
adaptation: a local Socket.IO text chat with its own locked dependencies and
protocol/browser tests. It does not require installing the other project seeds.

[P10 — The Last Waystone](waystone-dialogue/browser/README.md) is a complete
browser rescue: equipment, Keeper negotiation, two river routes, current/cargo
decisions, five endings, illustrated situation, local resume and portable saves.
Campaign 0.4.0 adds a morning whose crew, transport and clinic depend on the
night. It preserves Python adventure 0.2.0 and standalone dialogue 0.1.3.
Human play remains pending; no RPG engine is required.

[P03 — Tokyo 80s](tokyo80s/README.md) is an original four-lane browser rhythm
stage consuming P08's actual synthesized soundtrack, with timing calibration,
Practice/Arcade, combo/Pulse, results and replay.

The remaining lines are described in [the seed](../SEED.md) and
[project registry](../registry/projects.json). Historical sources remain in
the archive. Add a working project only when it has concrete material, a
defined scope, acceptance criteria, and its own execution instructions.

[P02 — EVAL-001](../evaluations/chat-send-buffering/README.md) is an executable
task harness under `evaluations/`, using P11's app and tests without duplicating
the application. Its calibrated artifact gates do not establish model performance.


[P06 — Veilbreak](veil-arena/README.md) is a native Godot 4.6.3 boss trial with
physics movement/cover, blade/seal/ward choices, two phases and complete results,
pause and restart. Source and built PCK are delivered; PCK requires Godot.
This is new implementation, not recovery of the missing Unity starter.
