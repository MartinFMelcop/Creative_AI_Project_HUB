# A name on the road

An original visible intake composes **one unchanged `PreparedExpedition`** through
finite crafting, real Crossing encounters, earned preparation and remembered failure.
The same handle and independently chosen cloth accent stay on the field card while
actual discipline, equipped slots and acquired outfit determine available behavior.
This is a .NET10/Linux/browser product experiment, not a production browser direction,
Unity/netstandard library, approved character/class canon or historical creation parser.

## Execute

Use the pinned SDK10.0.401. From the maintained workspace:

```bash
dotnet build north-star/intake/Host/NorthStar.Intake.csproj -c Release
dotnet north-star/intake/Host/bin/Release/net10.0/NorthStar.Intake.dll --serve 8099 north-star/intake/web --seconds 600
```

Open `http://127.0.0.1:8099/`. The owner is ephemeral; closing it loses this session.
There is no account, new save format, journal integration, server identity or multiplayer.
Do not bind it publicly. Existing Linux/Windows downloadable scenes remain separate.

Submit the whole card, review its exact submitted version, then explicitly confirm.
Editing invalidates review. A form change alone does not submit a proposal. The
experimental handle is1–24 ASCII letters/digits/underscore/hyphen and stays fixed after
first confirmation. Copper/teal/violet are expression only, with no stat/supply bonus.
Background remains eligibility metadata, not a biography or hidden effect.

Anchor uses Brace; Lure uses Draw and requires Trailborn. Four slots are capacity;
only Brace, Draw and earned level2 Dash are implemented. Empty slots remain explicit.
There is no fuzzy matching, free-text skill interpretation, legacy ID normalization,
automatic prerequisite grant or adopted historical class/background fiction.

Only confirmation delegates the entire preparation to the existing owner. Pending
amendments block crafting/entry until reviewed and confirmed. During/after an encounter,
card changes refuse. Between encounters the same person can explicitly amend preparation
and accent, retaining actual XP, allocations, finite stock, attempts and used rigs.
Changing the card does not itself heal, refill resources, refund or start an encounter.

Starting4fiber+2binder, workbench and survey permission are disclosed experimental
setup inherited from the owner, not acquired world rewards. Each Plate/Trail rig costs
2fiber+1binder; every actual rig entry consumes one, including losses. Unprepared entry
spends no rig but disables discipline skill. The next actual Begin applies the existing
encounter's preparation/recovery rules; card confirmation does not perform that recovery.
Survey victory earns progression but is not final completion. A losing Wait policy
retains spent supplies and the confirmed person. No promise, time, redraw or browser field
creates XP, crafted goods, completion, return or delivery.

The visible original SVG observes confirmed accent/discipline and actual outfit; a
faded initial drawing is an unconfirmed preview. It is not a full avatar creator or
animation migration. Text remains available without motion. Browser interruption or
an uncertain command receipt requires an explicit read, with no automatic retry.
Revision checks refuse old intent; this is a bounded local contract, not distributed
exactly-once execution, an account security boundary or a participant consent finding.
