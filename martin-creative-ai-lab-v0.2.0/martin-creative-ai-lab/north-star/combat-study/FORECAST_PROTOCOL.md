# Bounded response forecast — acceptance protocol

Baseline:5c468f80bd44c9db0f56ab06477c9ab59509513c. This is implementing-team software
acceptance, not preregistered human research. Exploratory builds precede acceptance.

Consume the P05 method in Cinder.Core ResponseForecast/Game and its ResponseChecks:
one legal chosen action on an independent owner branch, announced consequences only,
stop before the next decision or at the terminal outcome. Source fiction, resources,
unit statistics and campaign policies do not transfer. No historical RMXP execution.

A: this consequential legacy method benefits the existing Treatment Line's DOT,
initiative, finite charges and pending response choices. B: earned passive acquisition
still needs a separate policy. C: CI readiness is verified; no Unity executable was
found in bounded PATH checks. A corrects qualitative legacy underinvestment.

The destination replays its private accepted commands into the SAME Trial implementation
with identical initial preparation and seed, preserving prior refusal text. There is
no parallel combat formula, persistent save/replay format or automatic action policy.
The forecast returns one detached conditional state. Pending Commit must stop before
Release/Break ward; no later player choice is assumed. The returned next initiative
queue is conditional information at that next decision, never the live HUD's queue.

Acceptance:
- Every original native/browser policy and fixed defeat remains exact.
- Repeated forecasts preserve the complete live snapshot and Room observation/sequence,
  including Last, RNG, effects, charges, breakbar, pending ward and spent rescue.
- A forecast equals the actual same action from the same context. Illegal actions,
  preparation/lifecycle commands and terminal forecasts refuse without live mutation.
- Review and confirmation are distinct. Confirmation binds the observed sequence;
  stale/duplicate confirmation and malformed envelopes refuse before Room mutation.
- The existing UI separates IF committed now from live facts, clears old inspections
  on commands/read/interruption, and never retries a lost confirmed action.
- Actual browser/HTTP controls detect a fabricated forecast HP renderer and preserve
  existing negatives. Seven-mode seed/portability grids are not expanded.

Limits: deterministic local software; no human understanding, preference, accessibility,
balance, Unity Editor, Windows gameplay/Steam, network/account authority or canon claim.
Independent Engineering/Science/Creative reviews selected the method. Subagents became
unavailable during implementation; primary performs implementation and execution, not
an additional independent validation. ENG015/SCI013/CRE005(A) inform temporal ownership,
rival controls and conditional information with actual cost.
