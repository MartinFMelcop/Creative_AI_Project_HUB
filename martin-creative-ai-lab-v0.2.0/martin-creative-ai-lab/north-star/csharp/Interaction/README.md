# The relay — real C# continuous-work interaction

This original local developer room makes work commitment and interruption observable.
The C#8/.NET Standard2.1 [InputTiming rules](../InputTiming/WorkRoom.cs) own time,
progress, resources and completion. The .NET10 loopback host owns a monotonic
Stopwatch; the browser only sends held intent and renders actual snapshots.
It is a migration/research consumer, not a different production-engine selection.
Unity/C#, Windows-first and Steam-intended remain the production direction.

```bash
dotnet build north-star/csharp/InteractionChecks/NorthStar.InteractionChecks.csproj -c Release
dotnet north-star/csharp/InteractionChecks/bin/Release/net10.0/NorthStar.InteractionChecks.dll /tmp/input-native.json
dotnet north-star/csharp/Interaction/bin/Release/net10.0/NorthStar.Interaction.dll --serve 8765 north-star/csharp/Interaction/web --seconds 180
```

Use the pinned SDK10.0.401; open `http://127.0.0.1:8765/`. Select a mechanism and
hold E or the pointer work control. Both catches take1000ms each. Grounding takes
1500ms, requires at least two integrity and spends one exactly once. It disables
the trial's incoming-hit intervention, but neither raises catches nor completes
the passage. Deliberately pass the exit with both catches raised and living health/
integrity. Skipping grounding is a valid no-cost route. The hit control is an
explicit developer intervention, not an autonomous enemy or full combat migration.

Release, station change/movement, pause/focus loss or harm discards partial work.
Harm at the same update as completion owns priority. Resume cannot revive a still-held
commitment: release to neutral and deliberately start a complete new attempt.
The browser renews intent every100ms. Missing input expires after600ms; expiry
interrupts at that deadline and requires explicit resume. This is a bounded lease,
not instantaneous knowledge of physical release: a lost release can remain valid
until expiry. There is no hardware latency, authenticated server or production
network delivery claim. The host binds127.0.0.1 only, accepts bounded same-origin
JSON and stops after an explicit1..600second lifetime. It creates no player saves.

## Material source differences

release grace at a sustain tail. Dangerous world work intentionally keeps neither:
interruption discards progress and rearming needs a new full hold. The instrument
executes these different policies rather than declaring one universally correct.
The retained Godot return gate has continuous geometry/combat and clamps per-frame
work contribution to50ms. This smaller C# room uses integer monotonic milliseconds,
explicit stations, an input lease and controlled hit intervention. It does not claim
full source/PCK physics, obstacle, range, balance or frame-clamp parity. Existing
Godot consumers and artifacts remain unchanged; old C# and Recovery formats remain
unchanged. No source fiction, generated atlas or final lore is adopted.
