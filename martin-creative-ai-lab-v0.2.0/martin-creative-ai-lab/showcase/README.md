# Technology portfolio evidence

The HUB remains a public **Design-Driven technology portfolio developed with
generative AI**. Its presentation centers on inspectable capabilities, design
choices, instruments, source resources and bounded execution evidence. Virgo
Diamond: The North Star is the principal product; P01–P11 are preserved technology
origins in controlled transition, not eleven independent release obligations.

The [portfolio overview](../../../README.md) connects each capability to an artifact
and its evidence. The [origin index](../projects/README.md) retains runnable examples,
reading editions and source setup. The [transition inventory](../labs/origins.json)
records dependencies, existing consumers, risks and extraction work.

The [three-brain library](../brains/README.md) supports selective consultation.
[Derived knowledge](../knowledge/README.md) preserves what execution actually
showed and where it applies. Neither storing documents in Git nor generating a
polished demonstration trains a model or establishes external validation.

implementation and historical sources. This presentation does not invent client
