THE COIL AND THE SHUTTERS — WINDOWS x64 LOCAL C# DEMONSTRATION

Extract the entire trusted AuthoredSceneWindows directory. From PowerShell 7:
  pwsh -NoProfile -File .\run-demo.ps1
Or supply the complete launcher path from another working directory. Optional
positional arguments select a port (1024..65535) and lifetime (1..600 seconds):
  pwsh -NoProfile -File .\run-demo.ps1 8769 600
Open the printed loopback URL in a graphical browser. Ctrl+C stops the host.
No SDK, Node, account or internet is needed at runtime. Windows x64 native .NET
requirements, PowerShell 7 and a graphical browser are required. This unsigned
local script may be refused by your organization's execution policy. Do not
bypass that policy, elevate, or change HTTP URL reservations to hide a refusal.
An occupied port or denied loopback prefix is an error. Hosted runner execution
does not establish ordinary user access or a physical Windows device assessment.

LOCAL CONTINUITY
Accepted actions are saved outside the immutable payload, by default:
  ..\NorthStarWindowsSaves\scene.json
This Windows default is separate from the Linux package's default. Set the
NORTH_STAR_SAVE_DIR environment variable to a fully qualified external directory
to select another location. Relative paths, links and reparse points are refused.
Existing saves resume after validation; corrupt, incompatible or non-file saves
refuse without reset. A missing save starts a new attempt. Explicit new day
retains history and changes day identity. An uncertain write blocks further
choices until reopening. Offline time changes nothing.

Keep backups. Stop the host before copying a save. The managed application bytes
are preserved from the Linux continuity archive, including compiled rule identity.
This avoids an invented migration; actual cross-platform save behavior still
requires separate execution evidence. No distributed/account/cloud synchronization,
arbitrary-filesystem or power-loss guarantee is claimed. The local host binds
127.0.0.1; it is not a public service or shared-world security boundary.
