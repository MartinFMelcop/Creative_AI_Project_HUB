THE COIL AND THE SHUTTERS — LOCAL AUTHOR-DIRECTED C# DEMO

From the extracted AuthoredSceneDemo directory:
  ./run-demo.sh
Open the loopback URL printed by the host (normally http://127.0.0.1:8768/).
The host stops after 300 seconds. Ctrl+C stops it earlier. To select a free port
and lifetime: ./run-demo.sh 8769 600
PORT must be 1024..65535; lifetime must be 1..600 seconds. The launcher works
from another working directory. It checks payload.sha256 before starting and
uses only its bundled .NET runtime. No SDK, Node, account or internet is needed.
A graphical browser, sha256sum, mkdir and compatible Linux x64 native libraries are
required. An occupied port is an error; stop that process or choose another port.

TRY THE ACTUAL CHOICES
Edda has unfinished shutters; a coil needs a far-bank handoff. Consult, survey,
and observe the actual threats. Rill's current offer needs explicit acceptance.
A promise is not departure, return or delivery. Work and travel cost light; a
successful delivery can leave local work unfinished. Refusal and withdrawal are
valid outcomes. Guided and solo journeys have different consequences. Read the
visible state and choose; time and browser redraw never complete an action.

CONTINUE THE SAME LOCAL ATTEMPT
The launcher creates or resumes a local save outside the verified package:
  ../NorthStarSaves/scene.json
The path is relative to the extracted AuthoredSceneDemo directory, not the
working directory from which you launch. Stopping or host expiry keeps accepted
choices, costs and actual encounter progress. Launch again to resume that file.
The page identifies local-save status, day and revision without exposing its path.
Browser refresh reads the current durable facts; it does not create another save.

An existing file is always opened for validation, never silently replaced. A
missing file creates a new attempt. A corrupt, incompatible, linked or directory
save refuses launch; preserve it for inspection rather than deleting it to hide
an error. If a write is uncertain, the process blocks further choices. Stop it
and launch again to validate and resume the same file. After an uncertain reply,
Read the current board observes what actually committed, without retrying intent.
A refused action does not become a saved choice. Offline time does not perform
work, complete a journey, return Rill or invent his fate.

Begin a new day is an explicit new day identity in the same retained history.
It does not erase earlier entries; this page does not provide an earlier-day
browser. The earlier session-only demo cannot be recovered retroactively.

To select another directory, supply its absolute path at launch:
  NORTH_STAR_SAVE_DIR='/absolute/path/My North Star saves' ./run-demo.sh
The launcher creates a missing selected directory. It does not change a valid
existing scene.json into a fresh run. Each extracted sibling package defaults to
the same adjacent NorthStarSaves directory: retain that directory when updating.
To move or copy your attempt, stop the host and copy scene.json to the selected
save directory alongside the separately acquired package. Keep a backup; a new
rules version may require explicit migration or refuse an incompatible save.
Do not copy a changing live save. No account, synchronization, Steam Cloud,
cryptographic authentication, arbitrary-filesystem durability or Windows storage
behavior is established. The application is a trusted local experiment bound to
127.0.0.1, not a public service or shared-world security boundary.
