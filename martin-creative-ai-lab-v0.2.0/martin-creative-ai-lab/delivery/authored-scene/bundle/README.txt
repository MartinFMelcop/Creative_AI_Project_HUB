THE COIL AND THE SHUTTERS — LOCAL AUTHOR-DIRECTED C# DEMO

From the extracted AuthoredSceneDemo directory:
  ./run-demo.sh
Open the loopback URL printed by the host (normally http://127.0.0.1:8768/).
The host stops after 300 seconds. Ctrl+C stops it earlier. To select a free port
and lifetime: ./run-demo.sh 8769 600
PORT must be 1024..65535; lifetime must be 1..600 seconds. The launcher works
from another working directory. It checks payload.sha256 before starting and
uses only its bundled .NET runtime. No SDK, Node, account or internet is needed.
A graphical browser, sha256sum and compatible Linux x64 native libraries are
required. An occupied port is an error; stop that process or choose another port.
