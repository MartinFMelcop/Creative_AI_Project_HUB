# Conhecimento transferível

Registre lições com problema, contexto, evidência, decisão, resultado e limites. Uma proposta de reuso entra como candidata em [transfers.json](../registry/transfers.json); reuso validado exige consumidor de destino e evidência.

O diretório comum ajuda a recuperar conhecimento. Ele não treina modelos automaticamente e não garante que uma sessão leia todo o conteúdo.
