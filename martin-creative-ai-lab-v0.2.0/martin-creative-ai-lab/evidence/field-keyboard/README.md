## Reproduce

Use SDK10.0.401 and the existing locked Playwright/Chromium instrument dependencies.
Build the existing host before recording its current binary identity:

```sh
dotnet build north-star/field-journey/Host/NorthStar.FieldJourney.csproj -c Release
node north-star/field-journey/tools/keyboard-browser.mjs dotnet EXTERNAL_NEW_OUTPUT evidence/field-keyboard/baseline/app.js
```

[Protocol](../../north-star/field-journey/tools/keyboard-protocol.json) predeclares
baseline, rivals and known-fault sensitivity. The preserved baseline is exact old
app.js, SHA256 `96e2fbfdcc36f5babe065f48c2126a2229189368dfdff0e4c1f17cacc7e006ae`.
It is routed against separately fingerprinted current HTML/CSS; this is a JavaScript
baseline, not an unchanged historical UI. Native Tab/Enter buttons already worked.
Browser/Host output identities vary by build/platform; outcomes and guard properties,
not cross-host binary equality, are the acceptance contract.

Logical unmodified keys are not remappable here; layouts requiring Shift for digits
or period are not validated. No physical latency, reaction-time, participant usability,
accessibility, preference, Unity Editor/Windows Player/Steam, secure multiplayer or
commercial acceptance claim follows. InputTiming's duration/lease owner was deliberately
not copied into this discrete command path. Compare production ownership, appropriate
